# SoftMarketRepo
Simulación del flujo GitFlow y aplicación de buenas prácticas en SoftMarket S.A.

# 🚀 Rama `release/v1.0` – Preparación de la primera versión estable

Esta rama contiene la versión candidata para el primer despliegue oficial del software desarrollado por SoftMarket S.A. Aquí se consolidan los cambios integrados desde `develop` y se realizan los últimos ajustes antes de pasar a producción (`main`).

## 🧾 Objetivo

- Realizar pruebas finales de integración.
- Ajustar documentación.
- Preparar el entorno de despliegue.
- Corregir detalles menores antes del lanzamiento.

## 📦 Contenido de la versión 1.0

- Refactorización del módulo de gestión de clientes.
- Corrección del cálculo de impuestos en facturación.
- Implementación de pruebas unitarias básicas.
- Diagrama del flujo de versionamiento.
- Documentación técnica inicial.

## ✅ Buenas prácticas aplicadas

- Revisión de código completa antes del merge.
- Validación de pruebas automáticas.
- Documentación actualizada.
- Preparación para etiquetado de versión (`v1.0`).

## 🔁 Flujo de trabajo

1. Merge desde `develop` hacia `release/v1.0`.
2. Validación final.
3. Merge hacia `main` para despliegue.
4. Etiquetado de versión (`v1.0`).
5. Eliminación de la rama una vez desplegada.

---

> Esta rama representa el paso final antes de liberar una versión estable del software.
