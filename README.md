# 🧩 Refactorizando el Caos en SoftMarket

Este repositorio simula la propuesta técnica presentada para mejorar el proceso de desarrollo de software en **SoftMarket S.A.**, una startup dedicada a crear soluciones a medida para pequeñas empresas.

## 🎯 Objetivo

Implementar buenas prácticas de desarrollo que resuelvan los problemas actuales de arquitectura, colaboración y calidad del software, mediante:

- Uso del modelo de versionamiento **GitFlow**.
- Aplicación de principios **SOLID**.
- Adopción de buenas prácticas complementarias (estilo de código, pruebas, documentación, control de calidad).
